\begin{abstract}
Long-horizon embodied agents rely on memory, and reusing memory brings a
decision they face over and over: commit to an object they remember, or keep
exploring. Work on embodied memory has improved what is stored and how it is
retrieved, but leaves the agent unable to tell when its memory is still
incomplete, and checks its choices only after it has travelled. We argue that
this commitment, not retrieval, is the main bottleneck. Analysing a strong
memory agent with simulator ground truth, we find that most navigation
failures are commitments to the wrong remembered object, typically made before
the goal has been seen, and that deciding before moving, within
the right region, recovers much of the loss. Making this decision without an
oracle requires the agent to represent what it has not yet seen, to scope its
choice to specific region instances rather than room names, and to learn that
exploring is often the right answer. We propose \ours, a region-scoped context
memory that addresses each in turn. The model's context holds one panorama per
region with unobserved space left visible; the agent commits in two steps
before it moves, first a region or ``explore'', then a target within that
region; and it is trained on streams in which the goal is often absent. On
LMEE-Bench and GOAT-Bench, \ours{} improves success rate by \tbd{+X} over
strong memory baselines and substantially reduces premature commitments.
\end{abstract}
